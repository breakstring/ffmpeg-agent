# 消费者技能合同（P23）

确认日期：2026-10-16。执行关联：CFK-813。

`ffmpeg-agent-connect` 负责接入已有服务与诊断；`ffmpeg-agent-media` 负责把用户选择的媒体处理为本地可用结果。两者可分别复制安装，各自自包含相同的 Python 3.10+ 标准库客户端，不要求服务端源码、Docker、FFmpeg 或模型 Key。

客户端唯一维护源为 `consumer/ffmpeg_agent_client/`；环境解析器从 `src/media_service/envfile.py` 同步。`scripts/sync-consumer-skills.py` 生成两份运行包与逐文件摘要，`--check` 检测漂移。修改公共逻辑后必须同步，不手改生成副本。服务端 Python 3.14 与消费者的最低版本分别验证。

消费者配置只有 `MEDIA_PUBLIC_BASE_URL` 和 `MEDIA_SERVICE_TOKEN`；后者为 Token 或显式小写 `null`。私有配置和任务记录不提交，Token 不进入命令参数、状态记录、日志或输出。HTTP 固定配置源，不跟随重定向；MCP 工具发现与 A2A Card 不能改变携带 Token 的目标。HTTPS 使用标准证书校验。

优先复用宿主已连接的远程 MCP。辅助命令 `upload` 生成本次具名 `file_id` 引用与稳定请求 ID，原生协议接受后由 `collect` 收集。独立 CLI 的 `run` 支持结构化 HTTP/MCP 和自然语言 HTTP/MCP/A2A；文件字节始终通过 HTTP。操作端口、参数和可用编码器从部署能力发现，省略参数保留服务默认。A2A 仅单次自然语言请求，不承诺多轮、流式或 0.3 兼容；MCP 适配本服务无状态 JSON Streamable HTTP，不提供 stdio 桥接。

任务记录按服务地址和输入身份绑定，保存冻结请求、幂等键和已接受 ID。未知接受结果只能用同记录、同请求恢复；已知 ID 后仅查询，不再次规划。超出最低 24 小时幂等保留窗口且接受结果未知时拒绝重提。记录串行锁定、私有落盘，输入变化拒绝继续。

计划生成、请求接受、取消请求成功都不代表媒体完成或停止。消费者等待媒体终态及 `inputs_released=true`；`needs_input`、`unsupported` 保留其决策和有界脱敏说明。等待超时返回可恢复状态，不自动取消或重新调用模型。媒体部分成功和下载部分失败均以非成功退出码呈现。

下载先取得有界租约，再从固定服务路由读取。输出目录必须为本次新建或具备相同请求所有权标记；已有文件只有大小和 SHA-256 一致才可复用，不能覆盖。集合逐成员下载并保存清单及失败项。成功或部分成功收集后仅 release 本记录的托管上传；失败、取消、需补充信息或未提交上传由显式 `release` 处理，活跃或接受结果未知时拒绝释放。原始本地文件和服务产物不自动删除。

验证包含私有临时目录下的协议/文件风险测试、独立复制技能的最低 Python 运行、实际现有服务的六操作与 HTTP/MCP/A2A 闭环，以及仅根据技能文档执行的独立前向验证。真实服务验收绑定精确镜像、技能包摘要和 fixture 身份。当前宿主验证不能替代真实双宿主机、其他操作系统、代理/TLS 部署和容量验证；既有阶段证据保留。
